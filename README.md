= awesome-zig
:toc: preamble
:icons: font

A curated list of awesome Zig projects, libraries, tools, and resources.

NOTE: This list was reset on 2026-05-27 as a fresh start. Earlier entries that were lost in a `.md` → `.adoc` migration accident are not restored verbatim — contributions welcome to rebuild the catalogue.

== Compilers and Toolchains

* https://github.com/ziglang/zig[ziglang/zig] — The Zig programming language and compiler.
* https://github.com/zigtools/zls[zigtools/zls] — Zig Language Server.

== Build Systems and Package Managers

* https://github.com/zigtools/zig-build-utils[zig-build-utils] — Helpers and patterns for `build.zig`.

== Webview / UI Shells

* https://github.com/hyperpolymath/gossamer[hyperpolymath/gossamer] — Cross-platform desktop webview shell with Zig FFI. Linearly-typed wrapper around platform webviews.

== HTTP and Networking

* https://github.com/karlseguin/http.zig[karlseguin/http.zig] — HTTP server library for Zig.

== Concurrency

* https://github.com/mitchellh/libxev[mitchellh/libxev] — Cross-platform event loop.

== FFI and Interop

* https://github.com/llogiq/zig-ffi-examples[zig-ffi-examples] — Reference examples for FFI bindings between Zig and other languages.

== Game Development

* https://github.com/floooh/sokol-zig[floooh/sokol-zig] — Bindings for the Sokol cross-platform libraries.

== Embedded and Bare Metal

* https://github.com/ZigEmbeddedGroup/microzig[ZigEmbeddedGroup/microzig] — Embedded Zig framework.

== Resources

* https://ziglang.org/learn/[ziglang.org/learn] — Official learning resources.
* https://ziglearn.org/[ziglearn.org] — Community-maintained Zig tutorial.
* https://github.com/ziglang/zig/wiki[ziglang/zig/wiki] — Official Zig wiki on GitHub.

== Contributing

PRs welcome. Add entries under the most relevant section, alphabetically within the section. Each entry should have:

* A link to the project repository.
* A one-sentence description in plain English.
* Optional: a tag indicating maturity (`(WIP)`, `(production-ready)`, `(archived)`).

Avoid promotional language. The list is for orientation, not marketing.
